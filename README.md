# 🧮 Calculator

A clean, responsive, and interactive Calculator web application built using pure **HTML5**, **CSS3**, and **JavaScript**. This project demonstrates CSS Grid layout, DOM manipulation, event handling, and core arithmetic logic without relying on any external libraries.

## ✨ Features

* **Basic Arithmetic Operations:** Supports addition (`+`), subtraction (`−`), multiplication (`×`), and division (`÷`).
* **Decimal & Error Handling:** Handles floating-point numbers accurately and prevents common issues like division by zero or multiple consecutive operators.
* **Clear & Delete Controls:** Includes `AC` (All Clear) to reset the calculation and `DEL` (Delete) to remove the last entered digit.
* **Responsive Design:** Adapts smoothly to desktop, tablet, and mobile screens using CSS Grid.
* **Zero Dependencies:** Built completely with vanilla web technologies.

## 🛠️ Technologies Used

* **HTML5:** Semantic structure for the display screen and keypad buttons.
* **CSS3:** Modern styling, CSS Grid for button alignment, and interactive hover/active states.
* **JavaScript (ES6):** Event listeners for button clicks and mathematical expression evaluation.
